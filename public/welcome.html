A few things
worth knowing.

Less mystery before you get started.

What does Control Studio actually do?

It manages the configuration and release of AI features: prompts, models, evaluations, targeting, experiments, rollout safeguards, and workspace access. Your application uses the SDK or API to retrieve or execute these configurations.

Do I need my own API key?

Yes, for real model generation. Configure credentials for OpenAI, Anthropic, Gemini, or an AWS identity for Bedrock. You can explore configuration and targeting without making paid provider calls. A ChatGPT or Claude chat subscription is not the workspace token.

Can I change a prompt without redeploying?

After your application is integrated with the runtime, you can save and retrieve new configuration versions independently of an application deployment. Adoption depends on how your application fetches, watches, or caches configuration.

Where does my workspace run?

This installation runs locally. The project also includes Docker deployment and backup tooling for a self-hosted server. Hosting and provider accounts require their own setup.

What happens if a release needs to stop?

Use the rollout controls, configured quality guards, and version history to pause, roll back, or restore a prior configuration. Review your fallback behavior: stopping an AI configuration selects its default variation rather than guaranteeing that no model executes.
